# CVTailor Configuration

Stores your personal profile data, resume variants, master templates, and API credentials.

* **`applicant_info.json`**: Your core personal information, target salary, and job scoring preferences.
* **`resume_variants/`**: Houses your JSON claim profiles for different target roles.
* **`resume_template/`**: Contains your master resume `.docx` layout.
* **`credentials/`**: Secure storage for your API keys.
